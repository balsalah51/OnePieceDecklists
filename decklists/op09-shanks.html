How it plays

Staples from lists on this page

Red OP09 Shanks is the older Red Hair leader - not green OP17 Shanks. Hosted lists keep the Red Hair pile and splash an OP17 Newgate body.

Consensus list

Averaged from 3 lists on this page, using the 3 that play OP17 so the 50-card core includes the new set, then filled to 50 cards.
